# AGENTS.md

Guide for AI coding agents (and humans) working in this repo. Read this before changing anything.

## What this is

Urban Dreams is a static art site: 23 street photographs of Warsaw re-rendered by a neural style-transfer
model, each pinned to the spot it was taken. Vite 8 + React 19 + TypeScript + MapLibre. No backend, no
runtime data fetching, no blockchain. Deployed on Vercel.

## Commands

| Task | Command |
|---|---|
| Dev server | `npm run dev` → http://localhost:5173 |
| Everything CI runs | `npm run check` (typecheck → lint → unit → build) |
| E2E (builds + serves on :4173) | `npm run test:e2e` |
| Rebuild media from originals | `npm run media` (see "Media" below) |
| README screenshots | `npm run build && npx vite preview --port 4173 &` then `npm run screenshots` |

Run `npm run check` before you say you're done. Run `npm run test:e2e` if you touched UI, routing or content.

## Invariants — do not break

1. **No runtime network dependency for content.** Works and media are bundled/served from this repo.
   The only third-party request is base-map tiles. `tests/e2e` has an offline test that enforces this.
2. **Content is validated.** Every file in `content/works/` must pass `WorkSchema`; ids are sequential from 0;
   filename is `NN-<slug>.json`. Invalid content fails the build and raises the dev error overlay.
3. **zod stays out of the bundle.** Runtime code imports *types* from `schema.ts`, never values.
4. **Never crop artwork** in detail views: `object-fit: contain`. Grid cards may cover-crop posters.
5. **Accessible map.** Pins are focusable buttons with a real name (title, style, district) and open on
   Enter/Space; focus moves into the preview and returns to the pin on close. Keep both e2e checks green.
6. **Selection state lives in the URL** (`/?work=<slug>`, `/works?style=<style>`) so every view is shareable.
7. **Respect `prefers-reduced-motion`**: new animations must be covered by the global rule in `base.css`
   or handle it explicitly (see `Sky`).
8. Keep it simple: no state libraries, no CSS frameworks, no UI kits. Plain CSS next to the component.

## Recipes

**Add a work**
1. Put the original (GIF/PNG/JPEG) somewhere reachable; add `{ "slug", "cid" }` to `scripts/media-sources.json`
   (or seed locally: `node scripts/sync-media.ts --seed <dir> --only <slug>`).
2. Create `content/works/NN-<slug>.json` with the next id (copy an existing file for the shape).
3. `npm run media -- --only <slug>` → writes `public/media/works/<slug>.*` and updates `content/media.json`.
4. `npm run check && npm run test:e2e` (e2e counts pins/cards from `media.json`).

**Change the base map**: edit the `DUSK` palette in `src/components/map/mapStyles.ts` (MapLibre style spec, OpenMapTiles schema,
OpenFreeMap source). Keep its colours in sync with `tokens.css`. The OpenFreeMap/OpenMapTiles/OSM
attribution is legally required; don't remove it.

## Conventions

- Conventional Commits (`feat:`, `fix:`, `refactor:`, `chore:`, `docs:`, `test:`, `perf:`).
- Imports: `@/…` alias for `src/`, explicit `.ts`/`.tsx` extensions, `import type` for types.
- Selectors for tests: `data-testid` on stable hooks (`pin-<slug>`, `work-card`, `work-preview`, `work-page`).
- Scripts in `scripts/` run with plain `node` (Node ≥ 22.18 type stripping): erasable TS syntax only.

## Media

Originals are large animated GIFs (~250 MB total) and are **not** committed. They are cached in
`.media-cache/originals/<cid>` and fetched sequentially from the Filebase IPFS gateway when missing
(ipfs.io and most public gateways rate-limit to 429). Outputs are deterministic for a given script version.
